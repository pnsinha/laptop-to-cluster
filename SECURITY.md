# Security policy

## Supported scope

Security reports are accepted for the current release and the default development branch. This static site has no visitor authentication, database, server runtime state, or project-operated remote execution service. Workflow scripts, dependency integrity, build/release automation, and accidental secret disclosure remain in scope.

## Report privately

Email `parmanandsinha@gmail.com` with subject `BSSw resource security report`. Include affected version/path, impact, reproduction steps, and only the minimum sanitized evidence required. Do not include live credentials or exploit public infrastructure.

The maintainer will acknowledge receipt when practical, assess severity, coordinate a fix and disclosure window, and credit reporters who request attribution. Public issues are appropriate only after disclosure is coordinated or for non-sensitive hardening requests.

If email is unavailable, use GitHub private vulnerability reporting when enabled. If both private channels are unavailable, contact BSSw at https://bssw.io/contact without sensitive exploit details and request a private handoff.
