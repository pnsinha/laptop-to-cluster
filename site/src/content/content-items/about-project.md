This public Astro guide helps scientific software practitioners translate multi-service laptop workflows into scheduler-managed, rootless-container workflows on shared HPC systems. Milestone 1 is deliberately bounded to a single-node Slurm and Apptainer baseline.

The local fellowship Statement of Work controls project deliverables and dates. Official BSSw program material supplies program context. Prior-fellow examples inform project-adopted practices but do not create program obligations. Project implementation choices are labeled as project decisions.

Start with [Scheduler as Orchestrator](/guide/scheduler-as-orchestrator/), follow the [getting-started path](/start/), or inspect the public [companion repository](https://github.com/pnsinha/laptop-to-cluster).
